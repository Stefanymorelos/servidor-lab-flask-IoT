# servidor-lab-flask-IoT
Pipeline IoT extremo a extremo desplegado en AWS: servidor Flask en EC2 que recibe datos de un cliente ESP32 conectado por WiFi, con documentación y código de distintas estrategias de persistencia (almacenamiento local, motor de base de datos, RDS y almacenamiento de objetos en S3). Proyecto desarrollado en el marco del curso de laboratorio de IoT.
